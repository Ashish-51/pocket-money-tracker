# 💰 Pocket Money Tracker

A smart, dual-themed financial tracker designed to help you manage your daily pocket money, track expenses, build savings habits, and make personal finance more engaging.

---

## ✨ Features

### 🎨 Dual Theme System

Switch instantly between two unique experiences directly from Settings without restarting the app.

#### 💼 Classic Finance Mode
- Clean Material Design 3 interface
- Professional banking-style dashboard
- Modern financial analytics
- Minimal and distraction-free layout

#### 🎮 Gamified Savings Mode
- Player levels and XP progression
- Savings achievements and badges
- Quest-style financial goals
- Animated progress tracking
- Reward-focused saving experience

---

- Income vs Expense Analysis

## 🚀 Setup & Installation

### Prerequisites

- Android Studio Hedgehog or newer
- Firebase Project
- Android Emulator or Physical Device

### Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Open the project in Android Studio

3. Sync Gradle files

4. Configure Firebase

5. Run the application on an emulator or Android device

## 🎯 Project Goal

Pocket Money Tracker was created to make personal finance management easier, smarter, and more motivating for students and young users.

By combining:

- Expense Tracking
- Savings Goals
- Real-Time Cloud Sync
- Gamification
- Modern Android Development

the app delivers a unique financial experience beyond traditional expense trackers.
